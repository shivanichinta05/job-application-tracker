# JobTrack Pro — Job Application Tracker

A full-stack, SaaS-style web application built with **Python, Flask, SQLite, Bootstrap 5, and Chart.js** to help job seekers organize, track, and analyze their job applications in one centralized dashboard.

---

## Features

- **Interactive Analytics Dashboard:** Real-time KPI cards (Total, Applied, Assessment, Interview, Offers, Rejected) and visual pipeline breakdowns using Chart.js (Doughnut & Bar charts).
- **Full CRUD Application Management:** Add, view, edit, and delete job applications with company name, role, job description, application link, location, date applied, status, and personal notes.
- **Search & Status Filtering:** Dynamically search applications by company or job role and filter by application stage.
- **Follow-up Management:** Track follow-up dates with automatic highlighting for **Overdue** and **Upcoming** follow-ups.
- **Modern Responsive UI:** Dark-slate and purple SaaS theme built with Bootstrap 5 and custom CSS.

---

## Tech Stack

- **Backend:** Python 3, Flask
- **Database:** SQLite3 (with parameterized SQL queries to prevent SQL injection)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
- **Data Visualization:** Chart.js
